Appointment Meeting Online

Appointment Meeting Online is a WordPress plugin that enables users to schedule appointments and create Zoom meetings with Shepherds.

🚀 Features
📅 Calendar Booking – Easy-to-use appointment booking calendar.
🎥 Zoom Integration – Create Zoom meetings directly from WordPress.
🛒 Buyer & Seller Support – Buyers and sellers can schedule meetings with Shepherds.
👨‍🏫 Shepherd Meetings – Manage online appointments between users and Shepherds.
📋 Meeting Post Type – View and manage all meetings from the WordPress admin panel.
⚙️ Admin Configuration – Dedicated settings and configuration section.
🔗 Meeting Management – Store and manage appointment and Zoom meeting details.
🔄 Workflow

Select Date & Time → Book Appointment → Create Zoom Meeting → Meet with Shepherd.
